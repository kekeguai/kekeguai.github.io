LibreTV - 免费在线视频搜索与观看平台 搭建教程

LibreTV 是一个基于 Next.js 的在线视频聚合搜索与观看平台，支持多源搜索、HLS 播放、观看进度、直播/IPTV、PWA 和亮暗主题。它只负责聚合和播放用户配置的第三方公开数据源，不自带影视内容。

本文以 LibreSpark/LibreTV 官方仓库当前版本为例，介绍使用 Docker Compose 部署的方法。

项目地址：LibreSpark/LibreTV

官方文档：libretv.is-an.org/wiki

一、准备服务器

建议使用 Debian 11/12、Ubuntu 22.04/24.04 等 Linux 系统，并准备 Docker、Docker Compose Plugin、一个域名、至少一个合法稳定的 Apple CMS 点播接口和一个自定义访问密码。

六、更新和备份

观看记录和配置主要保存在浏览器本地。升级前进入“设置 → 数据 → 配置导入导出”，保存导出的 JSON 文件。

七、常见检查命令

如果页面打不开，依次检查容器状态、8080 端口、防火墙、域名解析和反向代理配置。数据源搜索失败时，先在“源管理”中测试接口是否仍可访问。

本项目不存储、不制作视频内容，仅提供第三方公开接口的聚合和播放能力。请自行确认数据源及播放内容符合当地法律法规，并尊重版权。
